# gradi

**Open the app: https://mfjiae.github.io/gradi/**

Personal uni grade tracker (UTS 7-point GPA, WAM, target calculator, what-ifs, hurdles, sessions).
React + Vite, installable as a phone app (PWA), data stored on each device (IndexedDB). See CLAUDE.md for rules and status.

    npm install
    npm run dev     # local app
    npm test        # grade maths and data tests
